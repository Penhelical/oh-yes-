# oh-yes!
osu! clone in lua (osu!lua)

## Installation

Download source. 
1.Move files to osu!folder or folder with Songs folder(osu maps)
2.Download [Love2d](https://github.com/love2d/love) and move it into the folder
3.Create .bat file 
```bat
@echo off
start LOVE\love.exe ..\osu!

EXIT
```
4.Launch
